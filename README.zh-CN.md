## 首次分段，随后整句复现

粘贴英文后，本地生成器按句拆分原文，不调用翻译。生成器只导出 PhraseWeave JSON，使用 schema 8 保存英文原句和固定题序。练习到当前题时才通过 Index-Translate 翻译对应词、片段或整句，译文保存在练习中。

新练习卡片首次按逗号、分号、冒号或长破折号分段，再依据完整原句的依存关系，在可靠时拆出非从句前置状语、主语和谓语；主谓先组合，再加入前置状语。每个最小片段先练实义词和功能词，随后复现片段，最后复现完整原句。完成后再次练习只从完整原句开始。空格确认当前词元；不会时按回车先看音节，再按一次查看该词元答案。答对后从当前题首词重新输入，包括刚获提示的词元。后续词元不会提前显示。已保存的旧语块练习继续可用，当前只练其中的完整原句。

生成页的题序预览默认收起，展开后可按句选择查看。从句拆分暂时停用，已保存的旧卡片继续使用原有题序；详见 [ADR 0037](docs/adr/0037-pause-clause-splitting.md)。

旧 spaCy 语块生成器与回退练习实现保留备用，当前生成与练习入口不调用。旧卡片继续沿用原有题序；兼容约定见 [ADR 0034](docs/adr/0034-punctuation-segment-practice.md)。
