## 首次分段，随后整句复现

粘贴英文后，本地生成器按句拆分原文，不调用翻译。新导出的 PhraseWeave JSON 使用 schema 7，保存英文原句和固定题序；Markdown 只列英文原句。练习到当前题时才通过 Index-Translate 翻译该段或整句，译文保存在练习中。

默认情况下，新练习卡片首次依次单练每个逗号、分号、冒号或长破折号分隔片段，最后练完整原句；没有可分片段时只练整句。完成后再次练习只从完整原句开始。空格确认当前词元；不会时按回车先看音节，再按一次查看该词元答案。答对后从当前题首词重新输入，包括刚获提示的词元。后续词元不会提前显示。已保存的旧语块练习继续可用，当前只练其中的完整原句。

生成时可选开启“在标点分隔片段内拆分从句”（默认关闭）。开启后先练片段内的主句与从句，再练完整片段和整句；两种模式都会在生成页显示实际题序供检查。该选项只影响新卡片，详见 [ADR 0034](docs/adr/0034-punctuation-segment-practice.md)。

旧 spaCy 语块生成器与回退练习实现保留备用，当前生成与练习入口不调用。旧卡片继续沿用原有题序；兼容约定见 [ADR 0034](docs/adr/0034-punctuation-segment-practice.md)。
