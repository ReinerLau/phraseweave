# PhraseWeave

把用户给出的英文句子做成一条从必要词义走向完整句式的练习链；遇到有独立教学价值的短语时，再加入短语环节。学习者应能看清每一步增加了什么意义，并能借助相近的整句变体造出原句。直接用语言理解构建，不调用 PhraseWeave 生成器、句法拆分脚本或翻译服务。

## 构建练习链

1. **确定句意和模式。** 识别原句表达的事件、语气和核心结构，找出值得迁移的整句模式。变体保持这一模式的时态、语态、情态、肯否及实际用法。根据句意选择自然例句，不用 `Somebody does something.` 一类万能替身代替具体表达。
2. **明确词义。** 单列原句和变体中对理解、造句有帮助的实词，如动词、名词、形容词；承载原句核心动作或评价的词，即使常见也应列出。词义条目只列词典原形：动词用原形，名词用单数形，形容词和副词用原级。句中出现屈折形式时，在该词首次出现的完整句之前列出对应原形及基本词义，例如句中 `bought` 列 `buy`（动词：买），句中 `killing` 列 `kill`（动词：杀死）；词形变化留在完整句或有独立教学价值的短语中体现。同一原形已列过就不重复。代词、冠词、助动词、情态词、否定词等放在短语或完整句子里学习；需要辨别 `he/him` 等形式时，用句中对比体现，不另列代词词表。只列真正帮助理解原句和造句的单元。
3. **按需选择短语。** 仅当固定搭配、容易误解的结构，或整句变体不足以说明的词形变化提供独立教学价值时，才单列短语。能从词义和整句直接理解的组合留在完整句中学习。列出短语时，译文要体现组合或形式变化带来的意义；短语本身足以承载的意义保留为整体，不逐词拆散。时态、情态和否定通常放在完整句中体会。
4. **通过变体造句。** 在词义和按需选出的短语之后，先写用户原句，再围绕核心模式给出几个自然、意思清楚的完整变体，通常可用三到五个，模式值得多练时还可增加；让相邻例句尽量只更换一个有意义的成分。单列了多个核心词时，轮流替换它们所在的成分，让各词的作用都能通过整句对照看出来。变体可以使用原句以外的词，但译文须清楚显示变化；不要为凑数量造生硬句子。人名在中文译文中保留原文拼写，也不单列为词义条目。原文本身不完整或不规范时，仍逐字保留，不虚构修正。多句按原文顺序分别处理。

例如 `Killing him would not be easy` 可以按下面的英文单元顺序组织。`kill` 表示核心动作，`easy` 表示评价；先写原句，再用变体轮流替换动作和评价，每个新实词的原形放在相应变体之前，短语环节可以省去。原句保留没有句号的形式：

```text
kill
动词：杀死
easy
形容词：容易的
Killing him would not be easy
要杀死他并不容易
wise
形容词：明智的
Killing him would not be wise.
杀死他并不明智。
trust
动词：信任
Trusting him would not be wise.
信任他并不明智。
Trusting him would not be easy.
要信任他并不容易。
find
动词：找到
Finding him would not be easy.
要找到他并不容易。
```

## 练习链格式与检查

练习链采用 UTF-8 双语文本。用户明确要求纯文本时，在对话中用一个 `text` 代码块输出整条练习链，方便直接复制。每个英文单元独占一行，紧接下一行给出简体中文释义或译文；重复单元每次都重复译文。词义条目用原形并标词性，例如 `kill` 译为“动词：杀死”。列出的短语译文应显示组合或词形变化带来的意义；完整句按其自身含义自然翻译。代码块内不加空行、标题、编号、解释或行末空格；纯文本模式下代码块外不加说明。

输出前检查：词义条目只列有助于理解和造句的原形，句中首次出现的新实词已在此前列出其原形，不单列屈折形式；每个短语都有独立教学价值，且形式与译文对应；原句是本条练习链的首个完整句，并逐字保留原文及其标点；变体共享值得学习的模式且变化清楚；每个英文单元下方都有译文。缺少英文输入时请用户提供。

## 自动导入

默认在构建并检查练习链后执行以下步骤。

1. 用文件写入工具将整条练习链保存为临时 UTF-8 `.txt` 文件，保留原句、顺序和重复条目。文件中使用上面的交替行格式，不带代码围栏。为此次导入生成 UUID，并为原文选一个简短标题。
2. 运行 `phraseweave import --file <绝对路径> --title <标题> --request-id <UUID> --json`。通过参数数组或安全 shell 引用传参，英文内容只放在文件中。CLI 会连接或启动本地服务，导入后保持后台服务可用。
3. 确认命令成功，读取返回的 `exerciseId`、`count` 和 `url`。向用户返回练习标题、条目数和可点击的练习链接。
4. 导入失败时保留文件，说明实际错误和文件路径。重试相同内容使用同一个 UUID；修改内容后使用新 UUID。只有服务确认成功才声称已导入。

先解析已加载 Skill 文件的真实路径。若文件位于 PhraseWeave 仓库的 `skills/phraseweave/` 下，使用该仓库的开发版，即使当前工作目录在别处。若开发运行包尚未构建，先在仓库根目录运行 `pnpm cli:build`。执行导入时设置 `PHRASEWEAVE_DEV_RUNTIME=1`，用 `node` 执行该仓库下 `apps/cli/bin/phraseweave.mjs` 的绝对路径，并传入与上面相同的导入参数。其他安装方式使用全局 `phraseweave` 命令。无法使用本地服务时输出已完成的双语文本，并说明自动导入未完成。

用户可运行 `phraseweave stop` 结束导入开启的后台保活；仍在使用中的桌面或终端会话关闭后服务退出。用户明确要求纯文本时，只输出代码块，跳过自动导入。
