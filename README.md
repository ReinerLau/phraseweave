## 本地开发运行

在 Apple Silicon Mac 上安装依赖后，从仓库根目录运行 CLI：

```sh
pnpm install
pnpm cli:dev
```

启动后打开 <http://127.0.0.1:3000/>；按 `Ctrl-C` 停止服务。首次启动会准备 Python 运行环境，首次本地翻译会下载模型。

| 标签 | 含义 |
| --- | --- |
| `核心·词典匹配` | 词典找到词或短语，并通过当前句的功能角色过滤。 |
| `核心·实义词` | 未命中词典，但按当前句词性识别为实义词。 |
| `核心·动词 + 小品词` | 识别为连续的 `VERB + prt`，例如 `Hurry up`。 |
| `组合·名词短语` | 以名词为中心向左组成名词短语，例如 `green spaces`。 |
| `组合·渐进组合` | 将核心组或名词短语组继续组合，功能词随原文带入。 |
| `完成·完整原句` | 最后追加完整原句，不参与核心匹配。 |
