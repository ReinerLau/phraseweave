# 渐进学习单元生成器

PhraseWeave 的 `/generator` 页面由本机 CLI 提供。spaCy 分析在 Mac 上处理；整句中文提示默认由 Hy-MT2 在本机翻译，也可在页面选择 Index-Translate 公网翻译。选择公网时，英文原句会发送至 Bilibili。页面记住当前浏览器的翻译选择。生成结果可下载为 Markdown、PhraseWeave JSON，或点击“保存并进入练习”写入共享练习库。

从终端运行 `phraseweave`，或打开桌面启动器，均连接同一份本机服务；两个入口同时使用时不会启动第二份模型。Web UI 地址固定为 `http://127.0.0.1:3000/`，端口被占用时启动报错，不再自动更换。完整安装与手机访问方式见 [本地应用与远程访问](desktop.md)。

练习中点击已显示的英文单词可朗读，使用本地 Kokoro v1.0 的 `af_heart` 美式女声及正常语速。输入区只朗读当前显示的文字，空白词块不读隐藏答案。首次启动在 Python 环境准备完成后后台下载约 328 MB 的朗读模型，声音设置显示下载、加载、就绪或失败状态，失败可单独重试。准备最长等待 10 分钟，不阻塞练习和翻译；模型及英文发音资源齐备后，未缓存的新文本也能离线合成。模型锁定为 `hexgrad/Kokoro-82M` revision `f3ff3571791e39611d31c381e3a41a3af07b4987`，仅下载配置、主权重及 `af_heart` 声音，保存在 `~/.cache/phraseweave/lexical-chunks/kokoro/<revision>/`，不打入 npm 包。

音频由独立常驻 CPU 进程生成，单词生成超时 20 秒；英文发音使用本地 Misaki 和 eSpeak，音频独立于翻译模型。MP3 持久保存在 `PHRASEWEAVE_DATA_DIR/tts`，重启、升级及断网后复用，不自动过期。默认数据目录是 `~/Library/Application Support/PhraseWeave`。声音设置提供“清空朗读缓存”；手机通过同一本机服务使用及清理共享缓存。缓存键区分模型修订、声音、语速、朗读类型和文本；旧 Edge 音频保留但不再读取，手动清理同时清除新旧音频，不删除模型。没有在线朗读回退，下载、加载、繁忙、合成超时及进程退出分别提示，具体诊断记录在服务日志。

单词首次答错后，如果当前单元不能继续回退，会在英文填空句的句尾标点后同行显示按音节分段的 IPA，例如 `/kəm/ · /ˈpjuː/ · /tər/`，与句子之间留少量间距，宽度不足时在音节之间自然换行；字号与英文练习文字一致且至少 20px；仍填写完整单词。提示使用随客户端打包的美式 CMUdict 首项发音，多发音词不做语境选择；未知词不猜测。答对、切题或切换学习方向/展示方式后清除提示。资源及校验方法见 [离线音标词典](../tools/pronunciation/README.md)。

工具栏的“朗读原句”播放包含填空目标的完整英文句子，答题与答案状态均可使用，结算时隐藏。再次点击停止；整句与单词共用播放器，互相取消旧请求。整句最多 2,000 字符，生成超时 60 秒；模型准备完成后本地合成，MP3 与单词缓存一起清理。本机代理及手机网关等待朗读响应最多 65 秒，覆盖整句生成时限。词典音标可能与合成语音中的发音不同。

Chrome 扩展直接携带选中文本打开固定的本机 Web UI，文本放在 URL 片段中，页面读取后立即清除并预填到可编辑的输入框。选择翻译方式和导出格式，再点击「生成学习单元」开始处理；跳转和页面就绪不会自动生成。先查看预览，确认后点击「保存并进入练习」才保存和跳转。使用时保持终端中的 `phraseweave` 运行；无需桌面应用、Native Messaging 宿主或额外的 CLI 注册步骤。扩展不再打开 GitHub Pages。

本地模型固定为 `tencent/Hy-MT2-1.8B` revision `9a341cd1b679d3efd23b46e847b01745a71ed792`，首次本地生成时下载，后续复用缓存。按聊天模板翻译整句，单句英文输入上限为 512 个 tokenizer token；过长时显示错误。

公网翻译使用官方 `https://index-translate.bilibili.com/v1/chat/completions` 和 `Index-Translate-35B-A3B`，无需 API Key，逐句请求，每句超时 30 秒。公网生成不下载或加载 Hy-MT2。请求失败或译文截断时显示失败句序号，原文保留，用户可以重试或切换翻译方式；不会自动回退。启动仍需准备本地 Python 和 spaCy 依赖。

每个完整原句生成一条共用的中文提示。生成题序统一使用复习规则：组合学习单元前重放其直接来源。Markdown 与 PhraseWeave JSON 使用同一条题序。PhraseWeave JSON 使用 schema 4，包含稳定的 `unit_id`、直接来源 `source_unit_ids` 和原句上下文。

双引号只在分句和依存分析时忽略；输出的原句及学习单元按原文范围截取，整句保留完整的引号和句末标点。练习中这些标点固定显示，不参与填写或判分。此规则从算法版本 7 生效；旧计划和已丢失引号的练习需从原始英文重新生成。

练习页面当前暂时只开放“整句优先 + 全文”，隐藏学习方向和展示方式的切换入口。进入练习时统一使用这两个模式，从当前进度所属整句开始；缺少可靠原句分组或完整中文提示时阻止进入，提示重新生成并提供返回练习列表的入口。旧练习不做批量迁移或自动清理。此临时限制覆盖 [ADR 0022](adr/0022-switchable-learning-direction.md) 的自由切换与旧数据回退规则，以及 [ADR 0023](adr/0023-fulltext-practice-view.md) 的默认单题规则。渐进组合和单题的实现及类型仍保留，后续可在 `apps/client/utils/practiceModes.ts` 重新开放对应开关。

渐进组合保留生成题序，从较小的学习单元逐步组合并复习到完整原句；整句优先先练整句，答错时进入回退复习。两种方向均以当前填空词元为回车检查边界，先复习该位置及前面错误或空白位置对应的最小可练习单元，后续尚未练到的词元不单独加入复习；边界内全部正确但原题未填完时保留输入继续填写，见 [ADR 0027](adr/0027-current-word-recovery-boundary.md)。回退时再练原题中包含错误的直接组成单元，最后重试原题，跳过更深的中间组合；多个分支按来源顺序分别复习，返回后重新填写整个单元。中途再次出错只建立局部复习路径，完成后继续外层剩余步骤。见 [ADR 0026](adr/0026-shorten-word-recovery-path.md)。重新开放模式切换后，切换从当前单元重新开始；临时复习切回渐进组合时定位到原基础题之前同一单元最后一次出现的位置。学习方向和位置随本地练习保存，完整备份包含这些状态。定位与兼容规则见 [ADR 0022](adr/0022-switchable-learning-direction.md)。

当前默认使用全文展示。全文从开始就按粘贴文章的句序列出所有原句位置：前文中英对照，当前句使用填空，待练句仅用统一色条遮盖中文，不显示英文或填空。整句通过并推进后才揭开下一句，整篇完成后结算。全文支持上下滚动查看，目录展示全部基础题位置，可回看已答对题目并返回未完成题，快捷键不能跳题；回退复习继续可用。重新开放展示切换后，切换从当前句开始，保留回退路径并重置输入及当前计时；刷新、备份保留展示方式，重新练习从头开始。无法识别原句或缺少完整中文提示时需要重新生成。本次不保留段落、不调整翻译、不支持 EPUB。见 [ADR 0023](adr/0023-fulltext-practice-view.md)。
