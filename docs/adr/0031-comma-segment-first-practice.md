# 首次逗号分段，完成后整句复习

新生成流程的翻译与拆分时机已由 [ADR 0032](0032-lazy-practice-translation.md) 修订；本记录的首次题序及旧 schema 4 兼容规则继续适用。

新生成的练习卡片首次按英文逗号把每个原句分成非空连续片段，依原文顺序单练各段，最后练完整原句。例如 `A, B, C.` 的题序是 `A → B → C. → A, B, C.`。数字内部的逗号不作为分隔符；没有可分的逗号时只生成整句题。每个分段和完整原句分别翻译，分段题只展示本段中文提示及英文填空，整句题和全文前文使用完整原句译文。各题继续逐词空格确认，回车求助后从当前题的首词元重打；分段通过后才进入下一题，完整原句通过后才进入下一原句。

完成一张练习卡片的首次题序后，“再来一次”和以后打开该卡片都只练完整原句。中断或刷新未完成的首次练习仍从保存的分段或整句题继续。题序自动选择，不开放手动学习方向或单题展示开关。新导出保持 PhraseWeave schema 4，增加可选的 `practice_sequence: "comma-segments-v1"` 标记；分段题保存原文位置以便分组，但组成来源为空，不使用依存解析和旧语块回退。无此标记的已保存练习不迁移，仍按原有整句题序打开。

本决定修订 [ADR 0030](0030-sentence-token-replay.md) 的新生成内容、首次题序和求助后重打范围，以及 [ADR 0022](0022-switchable-learning-direction.md) 在当前开放流程中的默认学习方向。旧依存组合实现仍保留备用。
