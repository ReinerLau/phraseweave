# 在练习中切换学习方向

同一份练习保留完整单元库与组成关系，在练习页面选择“渐进组合”或“整句优先”。渐进组合保留生成器的复习题序；整句优先每句先练整句，答错时复用回退复习，组成单元再次出错才继续拆解，最终逐层重试。临时复习不推进基础题进度。这扩展了 [ADR 0013](0013-error-driven-review-recovery.md) 中固定基础题序的后续约定，填空展示继续遵循 [ADR 0017](0017-sentence-context-cloze.md)。

新练习及未保存学习方向的练习默认使用“整句优先”，初始位置对齐到当前进度所属整句，不插入额外语块起始题。已有练习明确保存的学习方向继续沿用；无法可靠识别原句分组时仍使用“渐进组合”。

切换从正在显示的单元重新开始，清空输入、答案提示和临时路径。切到整句优先时，当前语块作为额外起始题，答对后练所属整句；整句起点不重复。切回渐进组合时，普通基础题保留原出现位置；临时复习题使用最初出错基础题的位置作为锚点，找到同一单元 ID 在该位置之前最后一次出现的位置。正在重试原基础题时直接恢复锚点。选择最近一次复习而非首次出现，避免把已经走过的整段渐进路径重新练一遍；重复英文不能替代单元身份。

学习方向、整句优先起始题和原始题目位置一起保存，不保留两套进度。刷新回到当前基础题，重新练习清除额外起始题。生成 JSON 仍使用 schema 4，本地备份保留学习方向状态。整句由连续题序及只剩标点的原句上下文识别，不依赖单元 ID 的字符串格式；无法可靠分组的旧数据只提供渐进组合。本地服务显式进度更新允许后退，整份练习的过期写入保留已保存的学习方向与位置。
