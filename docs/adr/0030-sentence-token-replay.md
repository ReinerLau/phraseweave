# 整句逐词复现与求助后从头复习

## 决定

当前开放的练习从完整原句的第一个词元开始，以空格逐词确认。空格答错时保留当前草稿并短暂标红，仍停留在该词元。回车仅求助：第一次显示当前词元的音节，音节不可用时保持可继续求助；第二次只显示当前词元的英文答案。答题界面始终不显示后续词元答案。输入会收起答案显示，但本次求助状态一直保留到该词元答对。

求助后先正确输入并确认当前词元，随后清空本句并从第一个词元重新输入。刚求助的词元也必须在这轮从头复现中答对，才能进入后续词元。只有完整原句通过，才记录通过、推进基础题序或结算。切题、重新练习及刷新清除临时求助状态；刷新仍从当前完整原句开始。当前关闭普通整句输入的设置入口，已有 `wordSpaceCheck` 本地值不影响开放流程。

新生成流程只按原文分句并翻译整句，不使用 spaCy 解析依存树或组合学习单元。分句在本机使用确定性标点规则，保留原句拼写、引号和内部空白，处理段落、常见缩写和小数。Markdown 每句列出英文与中文；PhraseWeave JSON 继续使用 schema 4，每句一条完整原句记录，`source_unit_ids` 为空。新文件沿用现有导入、存储、全文展示与完成进度。

已保存的旧练习仍可打开：只从原有语块题序中选取完整原句，当前位置若落在语块上则映射到所属完整原句，不修改旧语块记录。旧 spaCy 生成模块、语块回退状态机、渐进组合和普通整句输入实现与测试保留备用；当前 UI 与生成入口均不调用它们。朗读模块仍可使用 spaCy 依赖。

本决定替代 [ADR 0017](0017-sentence-context-cloze.md) 的当前答案提示范围、[ADR 0022](0022-switchable-learning-direction.md) 的当前整句优先回退行为，以及 [ADR 0029](0029-space-submits-enter-rolls-back.md) 的当前回车动作。旧约定仍描述保留的备用模式。
