# 可选的从句拆分练习

生成器增加默认关闭的“在逗号分隔片段内拆分从句”选项。关闭时继续导出 schema 5 `lazy-comma-segments-v1`，已生成卡片及其进度不变。开启时在本机用固定版本 spaCy 解析原句，先沿用逗号边界，再在每个逗号分隔片段内部识别常见的宾语、状语、定语等从句。无法可靠定位的从句不强行拆分；语法模型不可用则生成失败并显示错误。

开启后的首次题序从原文中的连续小片段开始，按包含关系逐层练到所属的完整逗号分隔片段，最后练完整原句；相同范围只出现一次。嵌入式从句两侧的主句文本作为各自连续片段练习，不拼接不连续文字。完成首次题序后仍只练整句，逐题翻译、缓存及仅预取下一题的规则沿用 [ADR 0032](0032-lazy-practice-translation.md)。生成页在保存前展示真实题序，供用户判断拆分效果。

开启时导出 schema 6 `lazy-clause-segments-v1`。每条原句仍只有一条英文记录，额外保存有序的 `practice_spans`，其起止位置是原句的 UTF-16 偏移，末项为完整原句。浏览器与本地服务只使用已保存范围计算题目和校验进度，不在练习时重新解析。旧 schema 4/5 卡片不迁移、不重算题序或译文。旧依存语块渐进组合算法仍保留备用。
