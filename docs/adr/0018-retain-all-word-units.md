# 保留全部非标点词元单元

渐进学习计划不按词性过滤非标点词元的单词单元，包括 `DET`、`ADP`、`AUX`。若单词覆盖整句，同范围仍只输出整句单元。较大短语继续从全部词元组合；复习和答错回退可以引用这些单词单元作为直接来源。

先前 [ADR 0014](0014-filter-function-word-units.md) 过滤功能词，是因为逐单元中文提示难以自然翻译孤立功能词。现在每题展示完整原句及其整句中文提示，词元始终带有句子上下文，原过滤理由不再适用。此决定取代 ADR 0014 的过滤规则；[ADR 0016](0016-retain-available-review-sources.md) 的直接来源规则仍适用。

学习计划保持 schema 3，算法版本升至 5，旧计划须重新生成。PhraseWeave 导入 JSON 保持 schema 4。
