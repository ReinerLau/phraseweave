# 空格提交，回车只回退

练习需要两个不会互相覆盖的键位：一个负责提交或确认，一个负责回退。此前普通整句输入用回车提交，逐词空格检查模式又让空格和回车都能确认当前词元；回车因此在“推进”和“回退”之间摇摆，答对后答案页的回车还会直接切题，查看整句时容易误跳。

决定空格成为两种模式唯一的确认、提交与推进键。逐词空格检查模式下，空格确认当前词元，匹配时锁定并播放正确提示，未匹配时保留草稿并短暂标红；普通整句输入在最后一个词元激活时用空格提交整句，词间空格仍只移动到下一空位。回车只用于回退：逐词模式无论当前词元是否匹配都复习当前词元，普通整句模式无论整句是否已正确都按当前填空词元边界进入回退复习。匹配时按回车不确认、不播放正确音、不切词，当前草稿被丢弃，已确认前缀保留。普通整句模式若边界内已有错误，回车按原输入复习这些错误；若边界内全部正确，则把当前词元视为未填写后回退，因此正确输入也能进入复习。

整句答对后，关闭自动下一题时仍显示答案页，再按空格进入下一题；开启自动下一题时继续自动推进。答案页不再绑定回车切题，空格以及用户自定义的导航快捷键继续可用；此规则对逐词与整句两种模式一致。空白回车查看答案继续属于回退/求助路径，不受影响。由于回车不再提交，原先可关闭的“开启空格提交答案”设置失去意义，随本决定移除；旧 `spaceSubmitAnswer` 本地值不再读取，不做迁移。

本决定修订 [ADR 0027](0027-current-word-recovery-boundary.md) 中“回车检查/提交”的键位含义，回退范围和边界计算本身不变。判词、题序、学习进度、备份格式、schema 与服务端接口均不变，已有练习无需重新生成。
