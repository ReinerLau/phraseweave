# 按节点规则和显式依存路径生成学习单元

## 状态

已被 [ADR 0009](0009-postorder-head-only-paths.md) 取代。

## 背景

递归闭合和后续短语组合会让较小的短语状态被反复带入更大的短语，产生大量变体，也让一个节点的输出影响其他节点。学习单元应由依存树中可检查的关系和维护规则直接确定。

## 决策

1. 固定版本的 spaCy 提供词性、形态和依存树；JSON 规则声明可独立成单元的节点，以及从起始节点出发的依存路径槽位。
2. 路径槽位显式声明依存方向、标签和目标词条件；后续槽位可从此前命中的节点继续查找，因此规则可组合多个 head/child 路径，单元词数由槽位决定。
3. 每个单元由一个起始节点的规则直接生成。必需槽位未匹配时该规则不产出；可选槽位有匹配时纳入匹配项，无匹配时跳过。已生成单元不作为其他节点规则的输入。
4. 相同 token 集合只输出一次；来源片段以原文顺序记录，完整原句始终作为最后一个单元。计划与 PhraseWeave 输出结构保持不变，规则 schema 与摘要升级，旧计划需重新生成。

## 后果

- 可以从 `Tulane` 沿 `compound` 向上读取 `University`，也可以从 `University` 沿 `prep=in`、`pobj=USA` 等路径向下生成多词单元。
- 单元生成规则互相隔离，不会发生短语状态传播或未配置的通用组合。
- 规则维护者需明确配置每段依存路径；未配置的结构不会出现在输出中。
