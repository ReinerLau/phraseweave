# 保留可练习的直接来源

功能词单词单元被过滤后，较大单元可能只剩一个适合单独练习的直接来源。继续要求完整的两个来源会让这类单元失去回退复习。因此 `review` 题序与答错回退都使用仍保留的直接来源：一个来源时先练它再重试原单元，两个来源时沿用原顺序，没有来源时不回退。新导出使用 PhraseWeave schema 3，来源数组允许零个、一个或两个 ID；客户端继续接受旧 schema 1、2。这修订了 [ADR 0013](0013-error-driven-review-recovery.md) 的双来源回退约定，以及 [ADR 0014](0014-filter-function-word-units.md) 中来源缺失即清空关系的约定。
