# 错误词元复习后只重试直接组成单元与原题

词元偶尔输错后，逐层完整练习所有组合会把一次小失误变成长时间重练。回退复习继续沿已校验的组成关系定位错误或未填写部分的最小可练习单元，但练习路径改为这些错误单元、包含它们的原题直接组成单元及原题，跳过更深的中间组合。这取代 [ADR 0025](0025-select-recovery-sources-by-answer.md) 的逐层组合返回规则，保留将词元放回组合及原句中完整复现的要求。

例如组成关系为“整句 → buy a new computer → a new computer → computer”时，整句中 computer 写错后的题序为“computer → buy a new computer → 整句”。多个直接来源都受影响时，按来源顺序分别练完各分支的错误单元与该直接来源，最后重试原题；共享单元按 ID 去重，直接来源本身就是词元时只练一次。缺少词元来源时，使用已有的最小可练习单元。

中途组合单元再次失败时，对该单元应用同样的局部复习规则；该单元通过后继续外层剩余步骤，不重新开始已完成步骤。原题重试失败时按新作答替换该层路径。每次返回都清空输入，重新填写整个单元；历史通过及局部正确不能代替本次完整作答。

两种学习方向、单题与全文展示统一使用此规则，不新增用户设置。错误定位、300ms 反馈、判词、答案提示及位置或组成关系不可靠时的直接来源回退继续遵循 ADR 0025。基础题序、生成格式、进度存储及服务端 API 不变；临时路径仍不持久化，刷新回到所属基础题，已有练习无需重新生成。
