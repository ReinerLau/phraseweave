# 新练习按选定标点分段并保存题序

新生成的英文练习默认按逗号、分号、冒号和长破折号 `—` 划分非空连续片段，依原文顺序练各段，最后练完整原句。分号和冒号两侧都须有可练文字；数字内部的逗号和冒号、网址内部的符号不划分。撇号、引号、括号、连字符 `-`、短破折号 `–`、斜杠及其他符号不作为边界。句末 `.?!` 仍由分句流程处理。连续边界不生成空题；没有两个可练片段时只练整句。生成页为默认与可选从句模式都展示真实题序。

生成时保存每句的 `practice_spans`，使用原句的 UTF-16 偏移，末项为整句。新默认模式导出 schema 7 `lazy-punctuation-segments-v1`；可选从句模式先按新标点边界划分，再在片段内部拆从句，导出 schema 7 `lazy-punctuation-clause-segments-v1`。每句仍只有一条英文记录，译文在练习时逐题取得并缓存。浏览器和本地服务均按保存范围计算题目、续练和译文索引。

本决定修订 [ADR 0031](0031-comma-segment-first-practice.md) 的新卡片分段边界、[ADR 0032](0032-lazy-practice-translation.md) 的新卡片导出格式，以及 [ADR 0033](0033-optional-clause-practice.md) 的从句父片段。旧 schema 4/5/6 卡片及其题序、译文和进度不迁移、不重算。
