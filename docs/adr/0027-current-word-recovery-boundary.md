# 回退范围止于当前词元

练习输入不能跳过词元，后续空白只表示尚未练到，不能据此要求逐个回退。回车以提交时的当前填空词元为边界，只复习该位置及前面错误或空白位置对应的最小可练习单元，后续词元不单独加入复习。此决定修订 [ADR 0025](0025-select-recovery-sources-by-answer.md) 和 [ADR 0026](0026-shorten-word-recovery-path.md) 中对未填写部分的选择范围。

边界内全部正确但原题尚未填完时，保留输入、当前位置和原题继续填写，不记为通过。例如输入 `I like` 后回车继续填写；输入 `I like ` 已进入下一空白，再回车才复习该空白。完整原题答对后仍按原流程推进。错误复习后继续完整重试相关直接组成单元及原题，组合内仍可包含后续词元。

输入与词元边界在提交时一起冻结，沿用 300ms 反馈后回退；反馈只标记边界内的错误。只有输入快照的调用按规范化后的最后一个词元推导边界，空输入对应首词元；缺少快照或位置、组成关系不可靠时保留原有直接来源回退。规则统一适用于两种学习方向、单题、全文及嵌套临时复习题，不增加存储字段、服务端接口或用户设置，已有练习无需重新生成。
