# 网页版与桌面版复用同一客户端

> 桌面端资源与生成引擎的打包方式已由 ADR-0020 取代。

GitHub Pages 与 macOS 桌面版从同一个 `apps/client` 构建，页面、练习流程和生成器共用。两个构建只在资源基础路径、生成引擎连接方式及手机同步接收地址上使用不同配置。桌面版将静态客户端放在稳定的安全应用来源下，自动管理打包的本地生成引擎；网页版继续访问用户单独启动的本地服务。

浏览器扩展提供网页版和桌面版两个选中文本导入入口。网页入口沿用扩展会话存储及页面握手；桌面入口通过 Chrome Native Messaging 将文本交给 macOS 应用，再由相同的生成器页面完成生成、导入和练习。唤起链接只传一次性编号，不包含原文。

两端使用各自的 IndexedDB 保存练习和进度，不自动同步或迁移。桌面端向手机分享练习时，接收链接指向 GitHub Pages 的 `/receive` 页面。
