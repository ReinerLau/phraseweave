# 直达错误单元并逐层组合返回

> 返回路径已缩短为错误单元、原出错单元的直接组成单元及原题，见 [ADR 0026](0026-shorten-word-recovery-path.md)。本 ADR 的错误定位与兼容规则继续适用。

整句或组合单元只在一处卡住时，固定复习全部来源会重复练习正确部分；只筛选直接来源仍需连续答错许多层才能到达词元。渐进组合与整句优先统一按本次作答的错误或未填写位置，沿已校验的组成关系自动定位到最小可练习单元，并以来源顺序生成相关分支的后序复习题序：错误单元在前，相关组合在后，最初出错的题最后出现。全部正确的旁支不单独复习，同一题序中的共享单元按 ID 去重。这修订了 [ADR 0013](0013-error-driven-review-recovery.md)、[ADR 0016](0016-retain-available-review-sources.md) 和 [ADR 0022](0022-switchable-learning-direction.md) 中逐层答错才能继续拆解的规则。

下降过程不再要求逐层提交错误答案，答对后继续逐层完整练习相关组合，保留词元组合成原句的练习过程。中途组合题再次失败时建立嵌套复习路径，直接练新的错误单元后返回当时出错的组合题；该题通过后恢复外层后续步骤，不重复重试它，也不跳到整句。最初出错的题再次失败时，依据新作答替换该层复习题序。历史通过记录不代替本次判断，局部正确不自动记为单元通过。本规则适用于单题、全文展示及临时复习题。

失败提交时立即保留输入快照，沿用 300ms 错误反馈后再回退。判词规则继续遵循 [ADR 0017](0017-sentence-context-cloze.md)；通过原句上下文推导位置，按完整填空词的位置匹配来源，不按英文文本搜索。缺少快照、上下文或完整词位置无法对应、相关组成关系不可靠、错误位置没有来源完整覆盖时，保留原有全部直接来源回退；叶子单元仍原地重试并保留答案入口。

临时复习仍不改变基础题进度，也不持久化临时路径。生成题序、导入格式、进度存储及服务端 API 不变，已有练习无需重新生成。
