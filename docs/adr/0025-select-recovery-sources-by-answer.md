# 按本次作答选择回退复习分支

整句或组合单元只在一处卡住时，固定复习所有直接来源会反复练习本次已经答对的部分。渐进组合与整句优先统一按本次提交选择回退分支：只练包含错词或未填写位置的直接来源，全部正确的来源跳过；多个来源覆盖同一错误位置时全部保留，顺序沿用原来源顺序。这修订了 [ADR 0013](0013-error-driven-review-recovery.md)、[ADR 0016](0016-retain-available-review-sources.md) 和 [ADR 0022](0022-switchable-learning-direction.md) 中复习所有直接来源的规则。

继续先练直接来源，来源答错才进一步拆解，通过后逐层完整重试父单元。父单元重试失败时依据新的作答重新选择分支；历史通过记录不代替本次判断，局部正确不自动记为单元通过。本规则适用于单题、全文展示及临时复习题。

失败提交时立即保留输入快照，沿用 300ms 错误反馈后再回退。判词规则继续遵循 [ADR 0017](0017-sentence-context-cloze.md)；通过原句上下文推导位置，按完整填空词的位置匹配直接来源，不按英文文本搜索。缺少快照、上下文或完整词位置无法对应、错误位置没有来源覆盖时，保留原有全部来源回退；叶子单元仍原地重试并保留答案入口。

临时复习仍不改变基础题进度，也不持久化临时路径。生成题序、导入格式、进度存储及服务端 API 不变，已有练习无需重新生成。
