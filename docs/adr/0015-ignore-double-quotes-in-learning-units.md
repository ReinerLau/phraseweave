# 依存分析忽略双引号，输出保留原文

引号中的表达可能跨越学习单元边界；把双引号交给依存分析会改变解析结果、阻断相邻组合，还可能使最终整句只剩左引号。因此在分句和依存分析时忽略直双引号与弯双引号；单引号及单词内撇号继续按原文处理。其他句中标点按 [ADR 0012](0012-adjacent-subtree-closure.md) 的现行规则处理，相邻判断忽略其影响。

最初的实现直接删除原文双引号，导致整句答案和练习上下文丢失引号。从算法版本 7 起，解析文本保留字符到原文的偏移映射，单词、短语及其直接来源都按原文范围截取。整句覆盖完整原句，包括开闭引号和句末标点，并沿用最后一次整句组合的直接来源。这样保留原有依存树与渐进题序，同时让原句、中文翻译输入、Markdown 和 PhraseWeave JSON 保留原文引号。短语仍以词元边界截取，范围内的引号照原文保留，边界外的引号通过原句上下文固定显示。

此调整取代原先“英文答案也不保留双引号”的约定。旧计划须重新生成；已有练习可以继续使用，但已删除的引号无法从旧练习恢复。计划保持 schema 3，PhraseWeave JSON 保持 schema 4。
