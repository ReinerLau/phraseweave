# 默认练习拆分主语与谓语并先组合主谓核心

新生成的练习继续先按标点确定父片段，但句法边界只依据完整原句的固定版本 spaCy 依存分析。每个父片段仍可拆出完整的非从句前置状语；在能可靠确认片段内的完整前置名词性主语与后续主句谓语时，进一步拆出主语和谓语。不设词数门槛。祈使句、倒装句、无可定位的名词性主语及边界不可靠的片段不强行拆分，从句拆分仍暂停。

练习组合结构规定主语和谓语先组成主谓核心，再由前置状语与核心组成原标点片段。按原文顺序先练子片段，再复现各自的组合片段，最终复现完整原句。例如 `In the morning she left.` 依次练 `In the morning`、`she`、`left.`、`she left.` 和整句；不生成 `In the morning she`。最小片段仍先练实义词与功能词题，较大组合片段只练完整复现。

预览和导出沿用 schema 8 的 `lazy-content-function-v1` 与已保存的 `practice_steps`。旧卡片及其题序不迁移、不重算。本决定扩展 [ADR 0036](0036-fronted-adjunct-practice.md) 的主谓核心处理，并补充 [ADR 0037](0037-pause-clause-splitting.md) 暂停从句拆分期间的新卡片规则。
