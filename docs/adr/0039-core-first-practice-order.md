# 先复现主谓核心，再加入单独拆出的成分

> 新卡片的递归成分组合由 [ADR 0040](0040-dependency-composition.md) 扩展；以下保留原题序决定的历史范围。

新生成练习在可可靠拆出主语和谓语时，先分别练主语、谓语并复现主谓核心，然后练单独拆出的前置成分，复现包含这些成分的原标点片段。是否有前置成分不影响主谓核心的拆分与复现。例：`In the morning she left.` 的片段题序为 `she`、`left.`、`she left.`、`In the morning`、完整原句。不生成 `In the morning she`。

现有算法只把完整的非从句前置状语作为主谓核心之外的独立句法片段；谓语后面的成分留在谓语片段内，多个标点片段在整句题中一并复现。边界不可靠时仍保留原片段。最小片段的实义词与功能词题不变，已保存的旧卡片不重排题序。

本决定调整 [ADR 0038](0038-subject-predicate-practice.md) 和 [ADR 0036](0036-fronted-adjunct-practice.md) 中前置成分先练的题序；其余拆分条件保持不变。
