# 整句来源缺失时用原句重试依存分析

[ADR 0015](0015-ignore-double-quotes-in-learning-units.md) 为稳定分句在依存分析前忽略双引号。某些包含多段引语的句子会因此改变句法结构：引号内容被挂到前面的名词上（例如 `self ← Nanahoshi`），该子树与当前片段不相邻，整句无法完成组合，最终整句单元的 `source_unit_ids` 为空。客户端只能把整句当作不可分解单元，答错后无法回退到 `had` 这类词元，只能清空整句重新填写。

决定保留 ADR 0015 的分句和常规依存分析规则，仅当某句的整句来源为空时，对已经切分出的该句原文（含双引号）再解析一次。若这次解析能得到完整的整句来源，则采用这次得到的单元和来源；树中仍过滤双引号词元，保持依赖树不含引号的约定。若重试仍无法得到整句来源，保留原结果。

此兜底只影响此前无法组合的句子，其他句子的单元与题序不变。算法版本升至 8，旧学习计划需重新生成；PhraseWeave JSON 保持 schema 4，客户端无需改动。已有练习不会自动获得新的来源关系，需要重新生成并导入。
