# 依存子短语逐层邻接闭合

`lexical-chunks` 改为按固定 spaCy 依存树后序生成单词单元，再让每个中心词从近到远接入已经闭合且与当前片段相邻的直接子短语。同一中心词下先遍历有非标点子节点的分支，再遍历叶节点，各组保持原文顺序；这样能让 `could` 一类叶节点靠近首次参与的组合。同层左右都可接入时，先输出各单侧及两侧合并，再向外扩展。相邻判断忽略标点和空白：两段之间没有其他非标点词元即可组合，组合结果仍保留原文中的标点；有字词间隔或子短语未闭合时仍阻断组合。整句最后输出，若已通过组合覆盖整句，则沿用该组合的直接来源；否则追加没有来源的整句。这样能稳定复现人工清单中的渐进顺序，并避免旧词对规则丢失限定词、重复拆开子短语或跳过中间字词。

该决策取代 ADR 0009、0010、0011 的生成与排序策略。英文单元完全由固定解析器和上述过程决定；模型只提供中文提示。旧规则文件和计划失效。PhraseWeave 导入格式后来按 [ADR 0013](0013-error-driven-review-recovery.md) 升级。严格遵循依存树意味着并列等结构可能产出半截中间片段，这是当前确定性策略的已接受结果。

忽略标点的邻接判断从算法版本 6 生效；旧学习计划须重新生成。学习计划保持 schema 3，PhraseWeave 导入 JSON 保持 schema 4；已有练习可继续使用，新的来源关系需重新生成练习才能获得。
