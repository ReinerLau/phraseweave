# 组合题只保存练习文本

新卡片的依存关系组合仍在生成时使用原文词位计算题序，保存后每道组合片段题只需要题型和练习文本。schema 10 的组合片段题统一保存 `{"kind":"segment","text":"…"}`，无论成分在原文中是否相邻；不保存 `span`、`source_spans` 或包围范围。实义词题、功能词填空题与整句题继续保存各自所需的范围和答案信息。

练习、翻译与朗读直接使用组合题的 `text`；续练仍按已保存题序的索引定位。schema 8、9 等旧卡片沿用各自已保存的步骤读取，不重新生成或迁移。

本决定简化 [ADR 0040](0040-dependency-composition.md) 的新卡片保存格式，不改变依存关系拆分和成分接回顺序。
