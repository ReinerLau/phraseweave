# 练习到当前题时拆分和翻译

生成时只在本机分句，导出 schema 5 和 `practice_sequence: "lazy-comma-segments-v1"`；每条原句只有一条英文记录，不含中文提示。Markdown 也只列原句。旧 schema 4 练习保持原有题序和译文。

首次练到原句时，按 ADR 0031 的规则动态拆逗号；每到一题才请求该段或整句的译文。译文以原句和段序号写入练习卡片，刷新及复习复用缓存。翻译或保存失败时停留在当前题，允许重试；已取回的译文在保存重试时不重复请求。进度由原句序号和段序号组成，回看已通过的原句只显示整句，返回未完成原句时恢复段序号。整张卡片完成后仅练整句。

全文展示继续列出全部原句位置。未练句没有译文时使用统一占位色条；前文在通过整句题后使用缓存的整句中文提示。无网络时，新题需要等待翻译，已缓存的题可继续练习。本决定修订 ADR 0031 中生成时拆分及预先翻译所有题目的行为。
