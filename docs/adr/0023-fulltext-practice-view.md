# 全文展示与逐句推进

一次粘贴生成的整篇文章按原句顺序连续练习，整篇完成后结算，不分章节。练习页面提供独立于学习方向的“单题 / 全文”展示选择，默认单题。全文沿用 [ADR 0017](0017-sentence-context-cloze.md) 的当前句填空和 [ADR 0022](0022-switchable-learning-direction.md) 的基础题序与回退复习；前文显示中英对照，后续原句隐藏。语块通过或临时复习通过不揭晓下一句，整句基础题通过并推进后才展开。这使前文提供上下文，同时保留渐进组合和整句优先的学习行为。

全文只允许滚动回看，不允许目录或快捷键跳题；当前作答通过记录与历史单元通过记录区分，状态层限制导航和最后一题结算。切换展示从当前句开始，之前的原句直接作为上下文而不补记通过，保留当前单元及回退路径，清空输入与答案提示并重新计时。切换学习方向仍按原基础题位置及单元 ID 定位，重复文本不合并。不建立单独解锁进度或第二套题序，以免展示切换产生两份学习状态。

展示方式与学习方向、起始题及原始位置一起保存，过期整包写入保留最新状态。刷新临时复习回到所属基础题，重新练习保留展示与方向但清除额外起始题。生成内容继续使用 schema 4；全文从原句分组还原句序，无法可靠分组时提示重新生成。本次不恢复原文段落，不改翻译或生成长度限制，不增加 EPUB 导入。
