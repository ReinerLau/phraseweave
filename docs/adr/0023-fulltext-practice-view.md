# 全文展示与逐句推进

一次粘贴生成的整篇文章按原句顺序连续练习，整篇完成后结算，不分章节。练习页面提供独立于学习方向的“单题 / 全文”展示选择，默认单题。全文沿用 [ADR 0017](0017-sentence-context-cloze.md) 的当前句填空和 [ADR 0022](0022-switchable-learning-direction.md) 的基础题序与回退复习；进入时一次列出整篇所有原句位置，前文显示中英对照，当前句显示中文提示与英文填空，后续原句使用统一色条遮盖中文，不显示英文或填空。色条是占位元素，不包含可复制的原句内容。此约定替代最初不列出后续原句的展示方式，让学习者从开始就能查看整篇句序；语块或临时复习通过不揭开下一句，只有整句基础题通过并推进才把下一条色条替换为练习内容。

全文允许上下滚动查看，不允许目录或快捷键跳题；目录列出完整基础题序，待练项不展示英文答案。当前练习区域融入列表而不占满一屏，推进、切换或刷新后定位当前句；仅滚动、查看答案或调整视口尺寸不会触发重新定位。当前作答通过记录与历史单元通过记录区分，状态层限制导航和最后一题结算。切换展示从当前句开始，之前的原句直接作为上下文而不补记通过，保留当前单元及回退路径，清空输入与答案提示并重新计时。切换学习方向仍按原基础题位置及单元 ID 定位，重复文本不合并。不建立单独解锁进度或第二套题序，以免展示切换产生两份学习状态。

展示方式与学习方向、起始题及原始位置一起保存，过期整包写入保留最新状态。刷新临时复习回到所属基础题，重新练习保留展示与方向但清除额外起始题。生成内容继续使用 schema 4；全文从原句分组还原句序，无法可靠分组时提示重新生成。本次不恢复原文段落，不改翻译或生成长度限制，不增加 EPUB 导入。
