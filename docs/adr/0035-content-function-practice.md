# 分段内先练实义词，再填功能词

新生成的练习继续按 [ADR 0034](0034-punctuation-segment-practice.md) 的标点划分片段，可选进一步拆分从句。每个最小片段先按原文顺序逐个练名词、实义动词、形容词、副词和数词，再固定显示这些实义词，一题填回其余词元。没有功能词时跳过填空题；没有可提取实义词时改为完整复现该片段。可选从句模式的较大组合片段保留完整复现题，完整原句始终最后练。缩写若在客户端属于一个词元，题目也不将其拆开。题目目标是准确复现原文。

新导出使用 schema 8，`practice_sequence` 为 `lazy-content-function-v1` 或 `lazy-content-function-clause-v1`。每句仍只有一条英文记录，`practice_steps` 按题序保存 UTF-16 `span`、题目 `kind`；单词题另存片段 `context_span`，功能词题另存待填的 `answer_word_indices`。生成器在保存前预览真实题序。单词中文提示结合所在片段翻译，其他题按题目文本翻译；译文仍在练到题目时取得并缓存，只预取下一题。

首次练习可从保存的步骤续练；完成后只复习整句。schema 4–7 和已保存的本地练习不迁移、不重算。本决定修订 ADR 0034 的新卡片首次题序，不改变旧卡片规则。
