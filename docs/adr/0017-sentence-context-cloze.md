# 整句提示与原句填空

渐进学习单元改为在完整英文原句中挖空输入，每题始终显示所属原句的中文译文。生成器只需为每句提供一条中文提示，导出单元前后的原文作为填空上下文；原文位置来自学习计划的 `span`，以免相同片段重复出现时挖错位置。填空成为唯一学习模式，语音、听写和音效功能退出；单元顺序与答错回退关系继续保留。此决定更新了 [ADR 0012](0012-adjacent-subtree-closure.md) 和 [ADR 0014](0014-filter-function-word-units.md) 中关于逐单元中文提示的约定。

填空展示保留练习原文中的标点，连字符、逗号、引号等固定显示，不参与填写或判分；`anti-social` 拆成两个填空，以空格切换，中间的 `-` 始终可见。单词内部的撇号仍需填写，直撇号与弯撇号等价；数字和货币符号仍属于答案。答案提示和答题后的展示采用同一排版。已有练习在客户端按原文派生填空，数据及备份格式不变。生成器在解析时忽略双引号、在输出中保留原文的规则见 [ADR 0015](0015-ignore-double-quotes-in-learning-units.md)。
