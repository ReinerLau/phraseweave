# 本机密码保护远程访问

扩展 ADR-0021 的远程认证：Cloudflare Tunnel 可以连接独立的本机密码网关，不再强制要求 Cloudflare Access。已有 Access 配置默认保持原认证方式及 JWT 校验。

密码模式使用一个本机管理的账号，共享原有练习库和学习进度；不引入多用户数据隔离或云端账号服务。隧道只连接监听回环地址的密码网关，页面、音频和 API 全部经过会话校验。网关通过流式代理连接固定的本机 Web UI；本机直接访问仍无需登录。网关或密码配置不可用时远程入口拒绝访问，不回退到直连 Web UI，本机服务仍可使用。

密码仅通过本机终端隐藏输入，独立私有文件保存随机盐及 scrypt 哈希。会话使用不持久化的安全 Cookie，服务端保存随机令牌，最多有效 24 小时；退出、重启和本机修改密码会使相关会话失效。手机浏览器恢复会话可能保留 Cookie，因此提供明确的退出入口。登录失败限流，登录、退出和写入请求均校验来源。
